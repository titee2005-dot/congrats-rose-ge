# Blooming Nineteen — Rose BNK48's Secret Garden 🌹🐰🎂

เว็บไซต์แฟนคลับฉลองวันเกิดครบรอบ **19 ปี** ของ **โรส — ปาณิสรา บูรณาภา (Rose BNK48 รุ่นที่ 6)**  
วันเกิด `01/11/2007` • ฉลองครบรอบ 19 ปี `01/11/2026`

## เอกลักษณ์งานดีไซน์ (Secret Rose Garden & Botanical Scrapbook)
- **ซุ้มโค้งดอกกุหลาบ & สมุดภาพกระดาษฝ้ายธรรมชาติ**: โทนสีชมพูกุหลาบพาสเทล (`#fad6e3` / `#d85280`), กระดาษฝ้ายอุ่น (`#fffbf8`), และสีเขียวใบเสจ (`#92baa0`) พร้อมกลีบกุหลาบปลิวละมุนทั่วหน้า
- **Timeline เถากุหลาบสลับซ้าย–ขวา 9 ฤดูกาล**: ร้อยเรียงเรื่องราวการเติบโตด้วยหมุดตราประทับครั่งกุหลาบ (`WaxSeal`), การ์ดโพลาลอยด์ติดเทปวาชิ (`WashiTape`), และดอกไม้บอกระดับการผลิบาน
- **โต๊ะเขียนโปสการ์ดแบบสมุดเปิด 2 หน้า + การ์ด 6 สไตล์ไม่ซ้ำกัน**:
  1. `pressed-rose` — จดหมายกุหลาบทับแห้งประทับตราครั่ง
  2. `bunny-polaroid` — โพลาลอยด์ขอบปักด้ายชมพูโบว์กระต่าย
  3. `vintage-airmail` — โปสการ์ดไปรษณีย์สวนกุหลาบขอบลายแอร์เมล + แสตมป์
  4. `lavender-note` — สมุดโน้ตห่วงกระดาษกริดสีลาเวนเดอร์ รุ่น 6
  5. `tea-party` — การ์ดเชิญปาร์ตี้น้ำชาฉลองวัย 19 ปี
  6. `sage-botanical` — การ์ดเรือนกระจกใบไม้ผลิสีเขียวเสจ
- **แนบรูปภาพ + พรีวิวสด + ดาวน์โหลดโปสการ์ด PNG (`html2canvas`)**
- **น้องกระต่าย Pixel Art วิ่งเล่นในสนามหญ้าสวนกุหลาบ**: กดทักทายน้องกระต่าย โยนแครอทเรียกมารุมกิน หรือกดเพิ่มจำนวนกระต่ายได้ตลอดเวลา
- **ระบบคัดกรองคำอวยพรหน้า `/admin`**: โปสการ์ดที่ส่งใหม่จะอยู่ในสถานะ `pending` เพื่อรอแอดมินอนุมัติก่อนติดแสดงบนกำแพงคำอวยพร (รหัสผ่านเริ่มต้น: `rose19`)

## วิธีรันโปรเจกต์
```bash
cd rose_birthday_react
npm install
npm run dev
```

## การเชื่อมต่อฐานข้อมูล Supabase (เมื่อพร้อมใช้งานออนไลน์จริง)
1. คัดลอกไฟล์ `.env.example` เป็น `.env` แล้วใส่ค่า:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_ADMIN_PASSWORD`
2. รันคำสั่ง SQL ในไฟล์ `supabase_setup.sql` บน Supabase SQL Editor เพื่อสร้างตาราง `public.wishes` และเปิด Realtime
   *(หากยังไม่ได้ตั้งค่า `.env` เว็บจะทำงานได้ทันทีในโหมดบันทึกข้อมูลบนเบราว์เซอร์อัตโนมัติ)*
